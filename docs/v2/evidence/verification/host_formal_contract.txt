# Host-adapter bounded control contract

The production module is [soc_job_adapter_m5.sv](../../../../rtl/v2/m5/soc_job_adapter_m5.sv). M6B.1's d16 SoC instantiates this exact module. This experiment does not prove the newer parameterized d64 adapter, CSR IRQ logic, cache payload or actual AXI write DMA.

[Assertions](../../../../formal/v2/m6c/host_properties.svh) check successful output completion requires stable child output ownership, both source-retirement/final-response flags, no outstanding transaction, correct expected words/bytes and equal nonzero AW/B/OKAY-B counters. They also check fatal priority, sticky ERROR, cleared publication on fault, captured configuration immutability and ACK only after an accepted release.

The first sampled step assumes common reset asserted. Later reset is arbitrary. Child completion, output metadata, source retirement, B-success flags and DMA counters are arbitrary input ports; there is no fairness assumption, legal-completion assumption or assertion that these inputs correspond to real AXI handshakes. SRAM, arithmetic, physical asynchronous-reset timing and inter-edge events are outside the proof. Yosys `async2sync` gives a normalized sampled-clock model.

Native Yosys cannot parse this module's package `import`. A verification-only derivative qualifies seven package constants and `config_t`, then appends properties. Original production source is unchanged. [Exact derivative/diff](../../../../docs/v2/m7/evidence/host_qualification.diff), [source hashes and commands](../../../../docs/v2/m6d/evidence/host_formal.json) document this mechanical transformation. No signal is tied off, narrowed, blackboxed or constrained to force safety.
